# ha-mcp: let Claude run your smart home (setup guide, @ai_with_nj)

ha-mcp is a free, open-source (MIT) server that connects AI assistants (Claude, ChatGPT, Gemini CLI, Cursor and 15+ others) to Home Assistant, the free open-source smart-home hub. You ask in plain words; it builds automations, edits dashboards and debugs devices.

Official repo: https://github.com/homeassistant-ai/ha-mcp · setup wizard: https://homeassistant-ai.github.io/ha-mcp/setup/ (README read 10 Nov 2026, v9.x).

## Option A: try the free demo (5 minutes, no devices)

No paid subscription needed. You get a hosted demo home to play with.

Windows:
1. Sign in at claude.ai (a free account works).
2. Open Windows PowerShell and run:
   ```powershell
   irm https://raw.githubusercontent.com/homeassistant-ai/ha-mcp/master/scripts/install-windows.ps1 | iex
   ```
3. Download Claude Desktop from claude.ai/download (or restart it: File, Exit).
4. Ask Claude: "Can you see my Home Assistant?"

Mac:
1. Sign in at claude.ai.
2. In Terminal run:
   ```sh
   curl -LsSf https://raw.githubusercontent.com/homeassistant-ai/ha-mcp/master/scripts/install-macos.sh | sh
   ```
3. Download or restart Claude Desktop, then ask the same question.

## Option B: connect your own Home Assistant

Needs Home Assistant 2026.8 or newer (install guide: home-assistant.io/installation; it runs on a Raspberry Pi or a spare PC).

1. Home Assistant 2026.11+: Settings, Marketplace, accept the first-run warning, search HA-MCP, Install. (2026.8 to 2026.10: HACS, search HA-MCP, Download.)
2. Restart Home Assistant.
3. Safer account: Settings, People, Add person, turn on Allow login, Local access only and Administrator. Use this account only for HA-MCP, never your own login.
4. Settings, Devices & Services, Add Integration, search HA-MCP, choose HA-MCP Server. Enter that account's user name and password (or a long-lived token), pick how clients connect (start with Secret URL for remote, or Local network), Submit.
5. Open the entry's Configure screen and copy the connect URL.
6. Paste that URL into your AI client as a custom connector / MCP server.

Run only one install method. Do not add two entries for the same server in one client.

## Safety

- Turn on Read Only Mode while you explore.
- Use approval rules for tools that change things.
- Edits are backed up automatically.
- Remote access is off until you enable it; keep it local if you don't need it.
