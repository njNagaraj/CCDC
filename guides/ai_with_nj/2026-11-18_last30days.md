# last30days: let Claude research Reddit, X and YouTube for you (@ai_with_nj)

last30days is a free, open-source (MIT) skill for Claude Code. You type `/last30days` and a topic. It searches Reddit, Hacker News, Polymarket, GitHub and (with setup) X, YouTube, TikTok and Instagram at the same time, ranks results by what real people upvoted, liked and watched in the last 30 days, and writes you one short brief. Repo: https://github.com/mvanhorn/last30days-skill (#4 on GitHub daily trending, 18 Nov 2026, 69,875 stars; v4.3.2 released 17 Nov 2026).

## What you need

- Claude Code. It needs a paid Claude plan (Pro or higher) or an API account; the free claude.ai plan does not include Claude Code.
- Python 3.12 or newer. Check with `python3 --version` (Windows: `python --version`). If it is older, install from https://www.python.org/downloads/
- Optional: Node.js, for the `npx` install path on other tools.

## Step 1: install Claude Code

- Windows (PowerShell): `irm https://claude.ai/install.ps1 | iex`
- Mac: `curl -fsSL https://claude.ai/install.sh | bash`
- Then open a new terminal, run `claude`, and log in in the browser.

Official docs: https://code.claude.com/docs/en/setup

## Step 2: add last30days

Inside Claude Code, type these two commands:

```
/plugin marketplace add mvanhorn/last30days-skill
/plugin install last30days
```

The marketplace install updates itself. To force an update later: `claude plugin update last30days@last30days-skill`

Using Codex, Cursor, Copilot or Gemini CLI instead? Run this in your terminal:

```
npx skills add mvanhorn/last30days-skill -g
```

## Step 3: first run

Type `/last30days` and a topic, for example `/last30days best budget phone`. The first run starts a setup wizard. It asks:

1. Whether it may read your browser cookies (for free X search). Say No if you are unsure. Reddit, Hacker News, Polymarket and GitHub still work with no keys.
2. Whether to search Reddit as your own logged-in account. The project's own docs warn this may breach Reddit's terms. We suggest No.
3. Whether you want a ScrapeCreators key (TikTok, Instagram, Threads, LinkedIn): 10,000 free calls, then pay as you go. Skip it to start.

Your brief is saved to `Documents/Last30Days` (Windows: `C:\Users\<you>\Documents\Last30Days`).

## Safe settings

- Cookies: you can turn cookie reads off at any time. Add `BROWSER_CONSENT=false` or `FROM_BROWSER=off` to `~/.config/last30days/.env`.
- On Windows, the cookie scan only supports Firefox.
- Reranking: if you add an OpenAI, xAI, OpenRouter or Gemini key, your topic and text snippets are sent to that provider. With no key it scores locally.
- Treat Reddit and X opinions as opinions. Check facts before you act on them.

## Troubleshooting

- "Python version" error: install Python 3.12+ from python.org and reopen the terminal.
- `/last30days` shows twice: you installed it with both the marketplace and `npx`. Keep one.
- No X results: X needs cookies, `XAI_API_KEY`, `XQUIK_API_KEY` or an X bearer token. See CONFIGURATION.md in the repo.
- No YouTube results: install yt-dlp (Mac: `brew install yt-dlp`). The first-run setup can also install it.
