# Sure: free money tracker with an AI assistant (setup guide, @ai_with_nj)

Sure is a free, open-source (AGPL-3.0) personal finance app. It is a community fork of Maybe Finance, whose team says it spent nearly $1 million building the original. It shows cashflow, net worth, budgets and investments, and an optional AI assistant answers questions about your money. You run it yourself, so your data stays on your own computer.

Official repo: https://github.com/we-promise/sure · site: https://sure.am (docs read 11 Nov 2026).

## Step 1: install Docker

Install Docker Desktop (Windows or Mac) or Docker Engine (Linux) from https://docs.docker.com/engine/install/ and start it. Check it works:

```bash
docker run hello-world
```

## Step 2: get Sure and start it

```bash
mkdir -p ~/docker-apps/sure
cd ~/docker-apps/sure
curl --fail --location --silent --show-error --output compose.yml https://raw.githubusercontent.com/we-promise/sure/main/compose.example.yml
docker compose up
```

(On Windows run these in PowerShell or Git Bash; `mkdir docker-apps\sure` works in PowerShell.)

The default file runs without extra setup on your own computer. If you will open it from outside your home network, follow "Step 3 (optional): Configure your environment" in docs/hosting/docker.md (it sets a secret key and passwords).

## Step 3: create your account

Open http://localhost:3000 and click "create your account". To keep it running in the background next time: `docker compose up -d`.

## Step 4: add your money

- Import bank statements as CSV (most Indian banks let you download one from net banking).
- PDF statement import uses the AI (see Step 5).
- Add investments: Indian mutual fund prices come from MFAPI.in with no API key.

Tip: import in smaller batches if you have years of history.

## Step 5: turn on the AI (optional)

The AI assistant answers questions about accounts, transactions, income, expenses and net worth, and auto-categorizes transactions. It needs a model:

- OpenAI-compatible: set `OPENAI_ACCESS_TOKEN` (paid API), or point `OPENAI_URI_BASE` at a local model server.
- Claude: set `ANTHROPIC_API_KEY` (paid API).
- No AI: everything else still works.

Settings go in a `.env` file next to compose.yml (template: `.env.example` in the repo), then run `docker compose up -d`. Full details: docs/hosting/ai.md.

Questions to try:
1. "How much did we save in the last 3 months?"
2. "Where could we cut back?"
3. "What did I spend on food delivery in October?"

## Good to know

- AI answers are informational only, not financial advice (the app says so).
- The phone app is a companion (login and balances); use the web app for everything else.
- Advanced: Claude Desktop and other agents can read your Sure data through its MCP endpoint (docs/hosting/mcp.md).
