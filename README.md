# CCDC: Content Creation & Digital Content

Public home for NJ's finished digital content. Everything here is public on the web, so it holds only files that are ready to publish.

## Layout

```
instagram/<account>/<post-id>/slide_01.jpg ...   Finished carousel slides (Instagram's API downloads them from here)
guides/<account>/<post-id>.md                    Free setup guides sent to people who comment the keyword
brand/<account>/                                 Profile photo, highlight covers, logos
```

Accounts: `ai_with_nj` (AI automations), `backend_with_nj`.

Post ids are `YYYY-MM-DD_<slug>`, the same ids as the private studio repo.

## Rules

- Only finished, public-ready files. No drafts, no tokens, no private data.
- Slides are 1080 x 1350 JPEG.
- Third-party images keep their credit and license as shown on the slide.
